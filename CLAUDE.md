# homebrew-devkin

This is DevKin's public distribution repository. It manages the Homebrew cask (`Casks/devkin.rb`) and the GitHub Release assets (the app `.dmg` downloads) together.

## Components

- `Casks/devkin.rb` — Homebrew cask. **Do not edit this file manually.** It is regenerated for every release by `scripts/build.sh` from the DevKin source repository.
- `scripts/release.sh` — Release script. Publishes the GitHub Release and commits/pushes the cask update.
- `.claude/skills/release-notes/` — Templates and writing rules for GitHub Release notes.

## Hard Rules

- Never upload source code here. Only documentation, `devkin.rb` for installation, and downloadable release files may be published.
- Never directly modify the automated files listed in `## Components`; always use the designated scripts.

## Release

Releases are performed automatically from the DevKin source repository: `build.sh` (build) → `release.sh` (publish). The release commit message must always follow the `release: vX.Y.Z` format.
